# API Reference

The AcadHub API is organized under the `/api` namespace.

## Authentication
- `POST /api/auth/signup`
- `POST /api/auth/login`
- `GET /api/auth/session`

## Profile
- `GET /api/profile`
- `PUT /api/profile`

## Registration Requests
- `GET /api/registration-requests`
- `PATCH /api/registration-requests/:id`

## Analytics
- `GET /api/analytics`

## Upload
- `POST /api/upload`

## AI
- `POST /api/ai`

## Collections
- `GET /api/db/:collection`
- `POST /api/db/:collection`
